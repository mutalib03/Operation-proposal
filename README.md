# Operation Surprise (proposal invitation)

## Run it
    npm install
    npm run dev        # preview locally
    npm run build      # creates /dist, upload that folder to any host

## Before you share
1. Edit `src/config.ts`: date, time, note, dress code.
2. Add the song as `public/liberian-girl.mp3`.
3. Host the `dist` folder (Netlify Drop, Vercel, Firebase Hosting...).
   Use an unguessable URL and delete it after the day.
